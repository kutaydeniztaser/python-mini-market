# 🛒 Mini Market Checkout System

A simple console-based mini market checkout system developed with Python as part of my learning journey.

## 📌 About the Project

This project simulates a basic market checkout process.  
The user enters product information and the program calculates the total amount and change, then generates a simple receipt.

## ⚙️ Features

- Market name input
- Product name, price and quantity input
- Automatic product total calculation
- Grand total calculation
- Customer payment input
- Change calculation
- Random 4-digit receipt number
- Console receipt output

## 🧠 Python Concepts Used

- Variables
- `input()` and `print()`
- `int` and `float`
- Basic arithmetic operations
- Type conversion
- `random.randint()`

## 🚀 Purpose

This project was created to practice the Python fundamentals I learned and apply them in a simple real-world scenario.
